# 发布中心 · 使用说明

## 快速开始

1. 双击项目目录里的 **`启动发布中心.bat`**（会弹出一个黑色命令行窗口，保持它开着）
2. 打开 `index.html`，左侧点 **「发布中心」**
3. 首次使用先在「发布设置」填入企业微信群机器人 Webhook，点「保存设置」，再点「发送测试消息」验证
4. 保持 **演练模式** 先跑一遍，确认流程没问题
5. 切到 **真实发布模式**，第一次会自动打开 Chrome 的各平台登录页 —— 每个平台手动登录一次即可，之后登录态会被记住

## 微信通知怎么配（企业微信群机器人）

1. 微信里建一个群（可以只有你自己，或者拉一个小群）
2. 群设置 → 群机器人 → 添加机器人 → 起名
3. 复制机器人给的 **Webhook 地址**（形如 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx`）
4. 粘贴到发布中心的「发布设置」里，保存

发布完成后会自动推送：成功/失败/跳过数量、失败原因、已发布链接。

## 账号真实导入（真实粉丝数）

「账号」页 → **从主页链接导入**，粘贴平台主页链接 → 点「抓取并导入」，会真的去平台抓当前粉丝数，不是模拟数据。

| 平台 | 可抓取方式 | 说明 |
|---|---|---|
| B站 | 公开接口直连 | 填 `space.bilibili.com/数字UID` 或直接填 UID |
| YouTube | 本机浏览器读取 | 填 `youtube.com/@handle` |
| X | 本机浏览器读取 | 填 `x.com/handle`，登录态更稳 |
| Instagram | 本机浏览器读取 | 填 `instagram.com/用户名`，登录后更稳 |
| TikTok | 本机浏览器读取 | 填 `tiktok.com/@用户名` |
| Discord | 邀请接口 | 只能填**服务器邀请链接** `discord.gg/xxx`，取的是成员数 |
| Reddit | 需登录 | 会被 Reddit 拦，先在专用 Chrome 登录 reddit.com；版块填 `reddit.com/r/xxx` |
| 抖音 / 小红书 | 需登录 | 先在专用 Chrome 登录对应平台，再抓取 |
| 视频号 | 不支持 | 没有公开主页，请在「手动添加」里填粉丝数 |

要点：
- 抓取由本机服务完成，所以**必须先把 `启动发布中心.bat` 打开**；线上版（social.lietrade.com）也能调本机服务。
- 抓取时会弹出一个**专用 Chrome 窗口**，属正常现象；它复用你的登录态，不读取密码。
- 抓到的账号会标 **真实**，粉丝数来自平台；每天点一次「同步全部真实账号」就会记录当天涨粉，趋势从导入那天开始累积。
- 平台改版或反爬调整会导致抓取失败，此时会明确报错，不会编数字——可以直接在「手动添加」里填真实粉丝数。

## 平台自动化程度

| 平台 | 状态 |
|---|---|
| X / Twitter、YouTube、Facebook、LinkedIn | 较稳定 |
| Instagram、TikTok、Threads、Reddit | 测试中（UI 改版时需调整） |
| Telegram、Pinterest | 实验 |
| B站、抖音、小红书、视频号 | 需人工点最后一步发布（自动生成素材待办） |

## 重要说明

- **风控风险真实存在**：X、Meta 系、TikTok、YouTube 都会检测自动化行为。工具内置了平台间随机间隔、失败重试、演练模式；建议控制频率，不要短时间内批量群发。没有任何方案能保证绝对不封号。
- **只操作你自己的账号**，不做点赞、评论、私信等互动自动化。
- **登录态保存在本机** `publisher-data/chrome-profile`，不上传任何服务器。
- **同一条内容每个平台只发一次**，失败后重试前请先去平台确认没有发出去，避免重复。

## 常见问题

**Q：发布服务连不上？**
A：确认 `启动发布中心.bat` 的窗口还开着，且显示「发布中心已启动：http://127.0.0.1:8899」。

**Q：8899 被占用？**
A：命令行里执行 `set PORT=8900 && node publisher\server.js`，同时把 `publish.js` 里的 `API` 端口改成 8900。

**Q：某平台总是失败？**
A：多半是该平台改版导致选择器失效。打开「运行日志」看具体报错，多数情况是在哪一步找不到按钮/输入框。也可以单独去该平台手动发一条。
